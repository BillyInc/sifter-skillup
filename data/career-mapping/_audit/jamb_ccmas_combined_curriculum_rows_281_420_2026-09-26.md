### Cross-cutting non-obvious patterns found

1. **Single CCMAS assignment can hide a combined-facet failure.** Examples: rows 285, 287, 292, 295, 304, 311, 335, 345, 349, 382, 409, 410, 415. This is why the four explicit two-component scope rows are not an adequate combined-curriculum detector.
2. **Partial scope is not automatically partial evidence quality.** Some records use lexical/title scope selection; course count alone doesn't prove the selected set maps the named award. Rows 302, 329, 402, 414, 418 have particularly low selections requiring a precise package/outcome and source-context check.
3. **Same title does not imply one curriculum.** Library and Information Science (rows 378–379 and 384–385), Hausa/Igbo (Arts vs Education), Home Economics, Hotel/Tourism, and other duplicate labels occur across different source-faculty contexts. Preserve each exact JAMB offering until the awarding-institution row shows identity.
4. **A declared two-package blend with no selected courses is an evidence defect, not a complete curriculum.** Rows 290, 306, 337 and 338 must not be called mapped just because component references exist.
5. **External NUC CCMAS intersections can identify overlooked component curricula.** For example, the NUC Agriculture CCMAS has Agricultural Economics/Farm Management content (AGE 307 farm-management/accounting/budget outcomes and AGR 202 agricultural economics/extension/rural sociology; see official [Agriculture CCMAS](https://www.nuc.edu.ng/wp-content/uploads/2022/12/Agriculture-CCMAS.pdf)); this is relevant to row 415 as a candidate but exact JAMB source offering evidence is still needed. The NUC CCMAS directory lists distinct programmes such as Accounting, Actuarial Science, Insurance, Information Systems, Pharmacy B.Pharm/PharmD, Petroleum Economics and Policy Studies and Journalism & Media Studies—each requires package crosswalk before asserting it applies to a JAMB row ([NUC CCMAS library](https://www.nuc.edu.ng/ccmas/)).
