## Execution method: one evidence packet closes several gates

Run the following loop once per area. The six task tracks are the packet outline, not six separate searches. The 24 matrix cells are mapping destinations, not 24 search assignments.

1. **Freeze the area's boundary.** Use its canonical area scope, source-backed tasks/activities, six fixed item families and four maturity horizons. Do not add a family, horizon, or area because a source suggests an adjacent topic; record it only if it fits the existing boundary.
2. **Build a gap sheet from the ledger before browsing.** List the area's 24 cells, six tracks, unassessed cells, every open `remaining_scope`, its existing source/query IDs, and (for D011) unchecked role-area pairs. Label each claim `covered by existing evidence`, `specific evidence missing`, `bounded no-hit candidate`, or `not applicable candidate`. No searches for already supported claims.
3. **Search by source packet, not by cell.** Use the six tracks as headings: foundations/prerequisites; methods, techniques and alternatives; tools/data; emerging/frontier; standards/resources; outputs/downstream tasks. Bundle only claims that share a source family and subject into a small set of explicit queries. Search official/primary evidence, research/handbooks and credible grey sources only where each can answer the stated gap. Open each source once, capture locator, context, assumptions/limits and outputs, then map it to every cell it actually supports.
4. **Terminalize the matrix and tracks together.** Reconcile each cell individually as `mapped`, `bounded_no_hit`, or `not_applicable`; keep it partial/unassessed only while a named material gap remains. Resolve each of the six tracks as `complete`, `bounded_no_hit`, or `not_applicable` from the same packet. A source found is not sufficient by itself: it must close that record's defined scope.
5. **Integrate role tasks within outputs.** For D011, disposition each stored role-area pair against role-specific task evidence while mapping outputs. Record conditional support only for the matching task; do not infer universal duties, fit, route ownership or learning prerequisites. Do not run a separate role sweep when one opened source supports several exact role-task records.
6. **Run exactly one final counter-search per area.** Search only the remaining weak points in the fixed matrix and the still-open prerequisite, alternative, complement, output and downstream-task questions. Record its bounded query set, source families, access limits and result. If a material finding appears, update only affected cells/tracks and repeat only that bounded check.
7. **Stop at the gate.** No source quota, global saturation claim or fresh domain-wide sweep is required. A failed fetch is an access limit, never a no-hit. Keep no-hit scope explicit and retain queries/results.

## Faster closeout operating rule

The unit of work is one **area packet**, not one source, cell, or track. There are four area packets left. Each has one fixed gap sheet, one evidence pass and one counter-search; its 24 cells, six tracks and any role tasks are reconciled together. Name target cell/task IDs before each search. Review indexed sources first and search again only when context, locator, maturity, source-family or claim-limit coverage is missing. A source may support several areas, but each area keeps its own claim-level disposition and boundary.

Use this sequence for every area:

1. **Reconcile (no browsing):** enumerate only open cell-specific `remaining_scope` entries, open tracks and uncovered D011 role-task pairs. Attach existing claim/source IDs. Remove a question when the existing record already answers it.
2. **Batch by shared evidence:** run one focused source packet for the remaining questions, grouped by source family. One inspected source can support multiple cells/tracks when it actually answers each claim. Do not run one query per matrix cell.
3. **Disposition in the same edit:** add claim context/locator/limits, update all supported cells, terminalize the matching task tracks, and update role-task evidence. Adding a source without updating the status is not progress completion.
4. **Counter-search once:** search only the residual risks after reconciliation. Record it even when it finds no new evidence. A finding reopens only its named target.
5. **Freeze the area:** close when every matrix cell and task is terminal, role checks are dispositioned, and the counter-search is clear. No general-purpose extra search pass follows.

The four open areas are the fixed finish line; do not add domains, families, horizons, tasks or general source quotas. Each gets one gap reconciliation, up to two grouped evidence-search batches and one final counter-search. If reconciliation identifies a specific named gap that the existing packet cannot answer, allow at most one targeted correction packet for that area before its counter-search; it must address only that recorded gap and narrow or terminalize it. This caps remaining discovery at **12 standard blocks plus at most four single-gap corrections: 16 bounded search blocks total**. Do not run a second correction for the same area; a material counter-search finding reopens only its named record and requires a documented decision before any additional search. Reconcile cells, tasks and role checks within those packets; they are overlapping destinations, not independent assignments.
