## Cross-cutting issue register

For the 2,314 candidates with known units, unit omission is confirmed. This means the audited scope cannot substantiate course credit loads or faithfully reproduce the metadata in the CCMAS source. No generator or source file was changed.
2. **Provenance has two layers and both must be kept distinct.** 1,893 selected course occurrences lack a complete course citation triple; 134 scopes lack a scope-level source record. Neither means “internet/source search found nothing.” Row 201's regenerated 72 package rows now have citations and three scope records; older aggregate values are stale.
3. **Current occurrence inventory under-records completed source checks.** It marks all 141 rows unverified, while row-by-row checkpoints already carry exact-cell findings in prior rows. At minimum, the current inventory conflicts with previously recorded evidence for rows 201–204, 211–229, and 232–235/240. Preserve proven checks; reconcile inventory/locators rather than duplicate research.
4. **Repeated codes need title- and source-row-specific locators.** Same-code distinct titles (ANA 301, HLM 301, HTM 403) cannot be audited using code-only joins. Repeated identical rows may have multiple contexts in the source package; repeated code is not enough to declare duplicate or discard a row. Row 249's PHS 202 record has a demonstrable header/OCR string in an outcome; its matching local JSON is not proof the text appears in the NUC source.
5. **Package coverage and JAMB offering applicability are separate.** Complete CCMAS parent packages, partial course slices and held unions describe current local scope, not an institution's approved timetable. All 140 identities have 141 parsed occurrence records; none of those records is currently marked exact-cell verified by the inventory. Where prior source checks have exact page/cell evidence, retain it; where only catalogue titles or concatenated tokens exist, keep institution identity unresolved.
6. **Primary-source fidelity remains open even where local parity is perfect.** The code/title/content/outcome join validates consistency between generated scopes and checked-in course JSON only. Original source materials and exact printed course locators must be checked for course code/title, credit units, contents, learning outcomes, repeated codes, page headers/OCR and package completeness. Do not promote the 2,320 local matches as “source verified.”
