## Method and evidence bar

I am checking each candidate against (a) the exact JAMB brochure title/faculty/offering row and institution cell when the primary PDF makes it recoverable; (b) the official NUC CCMAS course/component and its outcome/content locator; (c) the exact course set saved for that JAMB identity; and (d) the current domain links only as later-reassessment targets. Parsed institution arrays are not promoted to verified occurrences. A named blend is not permission to union whole programmes. A single-parent “full” scope is not called empty merely because `selected_courses` is empty.

Evidence dispositions:

- **Confirmed scope defect:** current selected scope demonstrably omits a substantive named facet or is empty for a combined curriculum. This does not itself approve replacement courses or downstream paths.
- **Evidence-needed candidate:** plausible gap/overreach, but title semantics, exact JAMB context, CCMAS outcomes, or source-package adequacy is not yet sufficient to decide.
- **Control / not a defect on present evidence:** the candidate scan is contradicted by current scoped courses or the course-selection contract.

Rows use the one-based `mappings` order (e.g. report row 145 is JSON index 144). Each future checkpoint will append a row-indexed section here and preserve prior decisions and source locators.
