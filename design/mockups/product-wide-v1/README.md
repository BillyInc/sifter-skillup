# Sifter LevelUp product-wide raster mockups

These are standalone PNG mockups for the Vite web surface and the Expo mobile surface. They are intentionally image deliverables, not browser previews.

The screen families are grounded in the current project routes and contracts:

- Discovery: Home, Explore, domains, programme detail, compare, roles, opportunities and My World.
- Account: sign-in and onboarding start.
- Admin: overview and guidance checkpoint.
- System: settings, flow map, components, navigation, card, search and feedback states.
- Responsive references: mobile Home, Explore and My World, with light and dark examples.

The content avoids invented universities, programmes, cut-offs, dates, organisations, salaries or statistics. Where the repository indicates that data is not available or connected, the mockup uses `Source pending`, `Coming soon` or `Locked` as the visible state.

The central relationship shown in the flow map is:

`Subjects → Programmes → Domains / sub-groups → Roles → Skills → Opportunities`

Admin guidance follows:

`Student guidance → Checkpoint → Review → Verify → Report`

`00-mockup-index.png` is a contact sheet. Open the individual PNGs for full-resolution review.

The `40-reference-*` files are the fidelity set built specifically against the supplied 1080×720 infographic references. They are the strongest visual direction for the core Home, domain, programme and role surfaces.

`route-screens/` contains one light and one dark PNG for every current non-layout `.tsx` route under `app/`, plus a route index and manifest. This is the route-by-route coverage set; the curated files above are the visual direction set.
