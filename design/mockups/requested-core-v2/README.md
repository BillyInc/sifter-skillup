# Requested core mockups

These images cover only the requested career-intelligence surfaces: intro carousel, Terms, onboarding, auth, Home, Explore, Opportunities, Profile and My World. Legacy/gaming routes are intentionally excluded.

Each screen has light and dark variants. The layouts deliberately differ: carousel storytelling, legal reading, persona selection, auth forms, connected home, exploratory search map, opportunity status board, profile identity card and saved-path constellation.

The copy uses the project’s real concepts and keeps unverified data states explicit.
