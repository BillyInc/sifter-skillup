# D078 guided learning-plan share-message design — 2026-10-10

Status: local implementation contract. The current share action uses the
generic privacy-safe copy through the device/browser share surface. Direct
platform publishing and tracked referrals are intentionally separate follow-up
work.

## Core message

> I just got my career mapping from Sifter LevelUp. You should do yours too.

The message may add a short route label and up to three learner-selected
learning themes. It must never add the learner’s name, institution, private
notes, admin information, hidden/review-only items or a claim of mastery,
employment or admission.

The current link is the public landing page:

`https://levelup.com.ng`

When referral tracking is enabled, the backend supplies a validated HTTPS
referral URL. The client does not invent a code. The referral URL replaces the
landing page in the same message contract and remains visibly identifiable as
a referral link in internal analytics and terms/privacy documentation.

## Platform copy contract

| Destination | Presentation |
|---|---|
| WhatsApp | Friendly two-line message, direct “Get yours here” link. |
| Facebook | Conversational post explaining that the mapping connects a programme to possible directions and next learning, followed by the link. |
| X/Twitter | Short version kept suitable for a character-limited post, with the link and optional route context. |
| Instagram | Caption-style copy with the link and a small set of relevant hashtags; no claim that the link is a clickable in-caption link on every client. |
| TikTok | Short caption suitable for a video or story, with the link and study/career hashtags. |
| Email/Outlook | Subject plus a fuller body explaining what the mapping does and inviting the recipient to start. |
| Generic/device share | The canonical copy used by the native/browser share sheet. |

These variants are generated by
`src/lib/learningPlanShare.ts`. Platform selection changes wording only; it
does not change the learner’s saved plan or expose extra data.

## Current and later behavior

Now:

- **Share summary** sends the identity-free generic message through the native
  or browser share surface, or copies it when browser sharing is unavailable.
- **Print / download** remains the authenticated full report and is separate
  from sharing.
- The message includes only the current route label and approved selected
  learning-item names.

Later:

- Add a platform chooser that previews the exact WhatsApp, Facebook, X,
  Instagram, TikTok and email copy before sharing.
- Add a revocable snapshot/deep link if a public share page is approved. A
  public link must show only the privacy-filtered summary, never the
  authenticated report.
- Add referral attribution only after the referral URL, consent, disclosure,
  expiry/revocation and analytics rules are implemented and tested.
- Direct posting to a social platform requires that platform’s approved app,
  permissions and user authorization. Until then, use the device/browser share
  surface or copy the prepared platform caption; do not claim that a post was
  published.

## Safety wording

The share copy describes a personal mapping and learning focus. It must not
say that the learner is qualified for a job, has mastered a skill, has been
admitted, or is guaranteed employment. The saved plan remains private unless
the learner deliberately shares the summary.
