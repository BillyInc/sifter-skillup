# D078 role-tool enrichment — 2026-10-16

This checkpoint adds five distinct, source-linked tool choices to each of the 19 currently routed D078 roles (95 role-tool contracts total). All are optional task supports—not role entry requirements, curriculum outcomes, qualifications, or proof of competence. Every tool has an explicit, resolvable `supports` relationship to that role’s bounded task context. When the route lists another included tool as an alternative, it also has a typed tool-to-tool `alternative_to` relationship. These links explain fit; they create no learning prerequisite or sequencing gate.

Existing domain/area tools reuse canonical identities. Specialist tools are added only where the role task supports their use. A tool’s role fit is a bounded synthesis of its documented capability and the reconciled role task profile; it is not presented as an employer mandate. Each record includes a plain-language explanation, the role-specific use and output, prerequisites, alternatives, limits, official reference, and a task-specific learning link with an attachment rationale.

## Evidence and boundary

- Tool product capabilities and learning links are taken from official vendor/project documentation or the already-reviewed D078 domain/area tool contracts. Role task scope is linked to the existing reconciled role-profile references in the graph.
- A match between a tool capability and a role task is a local, bounded recommendation; it does not claim the named tool is required by employers or taught in the Sociology curriculum.
- Tool choices remain optional. The core programme → domain foundation → area → role route remains usable without selecting or learning any tool option.
- Alternatives are task-level choices, not claims that products are identical. Paid access, institutional eligibility, privacy, licensing and data limitations are stated in the item contract.
- Source URLs were carried forward from existing D078 research where available; new specialist tool pages were selected from official project/provider documentation. No new searches are required to render these records.
