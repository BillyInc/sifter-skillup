## Disposition principles

- Resolve only clear semantic equivalents to an existing item in the assigned area catalogue; do not use fuzzy matching to reduce counts.
- Preserve every original relation type. In particular, alternatives remain alternatives; a complementary method or condition is not silently turned into a prerequisite or a sequence.
- A target that is a task output, task condition, safeguard, or grouped option is retained as an explanatory annotation when it is not a distinct item. This is a disposition, not deletion.
- The one new-item candidate is not promoted: it still needs its own full evidence-backed learning contract.
- `sequence_approved: false` is a task-scope hold, not a test of whether an item is universal. A valid conditional, complementary, or alternative relationship may later be sequence-approved for the route where it applies; this handoff does not perform that sequencing approval.
- External searches on 2026-10-10 checked primary/official AAA fieldwork guidance, UK Data Service qualitative-data guidance, AEA data provenance policy, OECD regulatory impact assessment guidance, and the Nigeria Budget Office I-Monitor portal. The sources have global scope unless explicitly Nigerian; lack of a Nigerian source does not disqualify globally relevant methods.
- Each JSON evidence entry records the source URL, locator/access date, and the claim it is being used to support. Where the graph supplied only a landing page and no pinpoint locator, that limitation is stated. A source supporting an item’s task context is not represented as proof that the exact relationship is mandatory.
