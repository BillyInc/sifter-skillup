The signature

The evidence line

§3 forbids inventing universities, cut-offs, salaries or statistics. The current product already honours this — it degrades to an em dash rather than guess. But it honours it silently, so a real figure and a placeholder look identical.

The proposal: every figure carries its provenance inline, set in the product's mono face. Not a tooltip, not a footnote — always visible. A student learns to read the confidence, and the constraint becomes the interface's most distinctive feature.

Two decisions for you

Where the brief and the codebase disagree

1 · Primary action colour

§8 asks for an orange primary action. The codebase's primary is blue (accent #1F5EFF); its only orange (#B45309) is a burnt amber used for warnings and streaks, too muddy to carry a call to action.

Shipped. The action colour is now #C2410C and blue is demoted to informational. The first candidate, #D9480F, was rejected on measurement: it carries white text at only 4.30:1, below AA and worse than the blue's 5.12:1. #C2410C reaches 5.18:1, so contrast improves rather than regresses.

2 · Typeface

§8 says “Inter-style typography”. The codebase deliberately runs Hanken Grotesk with Spline Sans Mono for data, with a comment noting it moved off Bricolage “into the redesign”. Hanken is Inter-like in character while being less generic, so this direction keeps it — and leans on the mono face to carry the evidence system. This page is set in the real fonts, not substitutes.

Scope

What this direction does not cover

  • The reference mockups were not supplied. §2A, §2B and Phase 5 depend on them; this direction derives from §8, §18 and §26 plus the existing theme, so it cannot be checked against the product owner's visual work.
  • Half the route tree is a different product. 88 routes; roughly half belong to the crypto/quant learning app. (tabs)/_layout.tsx already marks them “fold into My World in a later phase”. Nothing here restyles them.
  • Accessibility is a separate pass. About 9% of components carry any accessibility prop. Reduced motion, by contrast, is already implemented properly and honoured by six components.
